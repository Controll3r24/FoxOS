# FoxOS

Website for FoxOS, created by Controll3r24.

## Publish on GitHub Pages
1. Create a repository and upload the contents of this folder.
2. Settings, Pages, Source: deploy from branch `main`, folder `/ (root)`.
3. Your site goes live at `https://USERNAME.github.io/REPO/`.

## ISO
GitHub blocks files over 100 MB in a repository. Host the ISO in a Release and set its URL in the `data-src` and `href` of the `#dl` button in `index.html`. Until a reachable file exists, the button shows "Coming soon".
